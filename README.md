# Tearsheet

A personal macOS menu-bar app for region screenshots and light annotation. Spec and issues: [Linear](https://linear.app/howells/project/tearsheet-20262a013424).

```sh
scripts/install.sh
```

Then turn off System Settings → Keyboard → Keyboard Shortcuts → Screenshots → "Save picture of selected area as a file" so ⇧⌘4 reaches Tearsheet, and grant Screen Recording when asked.
