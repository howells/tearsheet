Region screenshots, a single-pen annotation editor and image extraction from Safari and Chrome, from the menu bar.

| Shortcut | Does |
|---|---|
| ⇧⌘4 | Capture a region to the clipboard |
| ⌥⇧⌘4 | Capture a region into the editor |
| ⌥⇧⌘6 | Capture the last region again |
| ⌥⇧⌘I | Copy the original images from the page in Safari or Chrome. Tab switches to this while selecting a region |

## Install

1. Unzip and move Tearsheet to Applications, then open it.
2. Allow Screen Recording when asked.
3. In System Settings → Keyboard → Keyboard Shortcuts → Screenshots, turn off both "selected area" shortcuts so ⇧⌘4 reaches Tearsheet. Tearsheet's Settings shows a reminder while either is on.
4. For image extraction, turn on Allow JavaScript from Apple Events: in Chrome under View → Developer, in Safari under Develop.

Requires macOS 26.
