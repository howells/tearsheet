Tearsheet Source on GitHub

Screenshots, copied the moment you let go.

Tearsheet lives in your menu bar. Capture any part of the screen, mark it up, or take the original images straight off a web page.

Download for Mac

Version 1.0 · macOS 26 · Apple silicon and Intel

1920 × 1080

  1. Drag across anything. It's on the clipboard when you let go, with a thumbnail you can drag into any app. ⇧⌘6 takes the same region again.

  2. One pen, seven tools: arrow, box, text, numbered steps, pixelate, highlighter and crop.

  3. Click an image in Safari or Chrome to copy the original file, full size, not a screenshot of it.

Before your first capture

  1. Move Tearsheet to Applications, open it, and allow Screen Recording when asked.

  2. In System Settings › Keyboard › Keyboard Shortcuts › Screenshots, turn off both “selected area” shortcuts so ⇧⌘4 reaches Tearsheet.

  3. To extract images, turn on Allow JavaScript from Apple Events: in Chrome under View › Developer, in Safari under Develop.
